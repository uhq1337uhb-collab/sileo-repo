🏝️ Island Repo

Dépôt Sileo communautaire — héberge Dynamic Island (Beta) (com.tudepzai.dynamicisland v0.0.1-115), un tweak qui injecte une île dynamique dans SpringBoard (rootless, var/jb).

Ajouter ce dépôt dans Sileo

  1. Sileo → onglet Sources → bouton +
  2. Collez : https://uhq1337uhb-collab.github.io/sileo-repo/
  3. Validez, puis cherchez Dynamic Island (Beta) et installez.

Deux variantes : …rootless (jailbreak rootless : Dopamine, palera1n sans --rootful) et …rootful (checkra1n, palera1n --rootful). Sileo n'affiche que celle qui correspond à ton jailbreak.

⚠️ Prérequis : iPhone jailbreaké rootless avec MobileSubstrate/ElleKit. Sans jailbreak, Sileo n'existe pas et ce paquet ne peut pas s'installer. Tweak beta amateur (build IA communautaire, v0.0.1) : bugs probables. Le .deb est servi tel quel, avec checksums MD5/SHA256 dans le fichier Release — vérifiable avant installation.
